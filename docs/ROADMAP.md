## Принципы следующих версий

1. Локальность остаётся базовым сценарием. Облако — опция, а не условие работы.
2. Любое изменение ИИ видно человеку и обратимо.
3. Граф не превращается в свалку: ритуалы, типы и помощь важнее свободного поля.
4. Никаких аккаунтов и телеметрии по умолчанию.

## v1.0 — Tauri без Node-sidecar

Tauri — это Rust-аналог Electron: системный webview + Rust-бэкенд, лёгкий и нативный.

- [x] Tauri shell и Linux portable-сборка (Node runtime пока sidecar)
- [ ] Перенос store, файлового watcher'а и SSE-замены на Tauri commands/events
- [ ] Перенос AI-прокси в Rust, ключи — в OS keychain
- [ ] MCP: либо Rust-сервер на `rmcp` с общим core-crate, либо Node-sidecar
- [ ] Автообновление, подпись сборок, бэкапы workspace
- [ ] Горячие клавиши на уровне приложения, меню, drag-n-drop файлов
- [ ] Офлайн-шрифты и полная автономность без dev-сервера

Критерий готовности: `src/api.ts` меняется на Tauri-клиент без переписывания компонентов; `workspace.json` совместим с предыдущими версиями.

## Анти-цели

- Не превращать SteppePlan в трекер задач или текстовый редактор.
- Не делать облако обязательным.
- Не давать агенту молча удалять или переписывать знания без следа.
- Не тащить тяжёлый UI-кит: визуальный язык задаётся CSS-переменными и несколькими компонентами.
